# Tag Music

Windows 和 Android 本地音乐播放器。支持曲库、标签筛选、歌单、队列、本地歌词、曲库备份和局域网双向同步。原创代码采用 MIT 许可，第三方组件另有许可。

## 局域网同步

1. 手机和电脑接入同一个家庭网络。电脑打开「设置 → 局域网同步 → 等待手机连接」，保持窗口打开。
2. 手机进入「设置 → 局域网同步」，输入电脑上显示的连接码，点击「立即同步」。成功后手机会记住连接码。

如果电脑显示多个连接码，选连接同一路由器的网卡对应的码。可在电脑上运行 `ipconfig`，按 WLAN 或以太网的 IPv4 地址对照。

同步范围包括标签、收藏、普通与智能歌单、筛选规则和主题设置。音乐文件由用户自行同步，两端各用自己的音乐路径。导入旧备份时，恢复预览也会显示自动匹配到的目录和歌曲数量。 [实现说明](docs/ARCHITECTURE.md#局域网同步与备份匹配)
