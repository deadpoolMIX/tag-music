# Tag Music

Tag Music 是一款 Windows 和 Android 本地音乐播放器，用标签整理曲库，再按规则筛选想听的歌。

- 支持标签筛选、普通和智能歌单、播放队列与本地 LRC 歌词。
- 支持曲库备份。手机和电脑在同一 Wi‑Fi 下可手动同步标签、歌单、筛选规则和主题设置，音乐文件由用户自行管理。

项目使用 Flutter 和 Dart。[项目架构](docs/ARCHITECTURE.md) · [构建方法](docs/VERIFICATION.md) · [源码发布](https://github.com/deadpoolMIX/tag-music/releases)
