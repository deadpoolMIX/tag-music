# 阶段工具与压缩细则

仅新阶段/续行需处理 Goal 或准备压缩时读取对应节；日常实现不必读。

## Goal 状态

- Goal 可用时核对已有目标，避免重复创建；新对话未带入目标则依据已确认计划及用户续行指令恢复同一目标。用户明确续行时按其授权继续；若Goal工具仍报告paused且无resume入口，不重复创建Goal、不谎称active，在HANDOFF记录工具状态与用户授权的差异。工具不可用就据实记录，不依赖工具状态代替项目记录。阶段未验收不得标 complete；paused 只用于用户明确暂停，其他状态遵守工具约束。

## 压缩与交接

- 有实际可用的主动压缩入口时执行压缩；没有时，提示“现在可以压缩了”，用可交互选项提供“继续工作 / 停止本轮并等待手动压缩”，等待明确选择。继续工作仅续行已授权事项；选择停止后立即停止，不再修改文件、操作 Goal 或执行其他收尾，等待用户手动压缩并明确续行。该选项只结束本轮，不联动阶段暂停或 Goal 状态；独立提出的阶段暂停仍按暂停规则处理。不把提示、选项点击或文档交接冒称为已经压缩。本规则仅适用于本项目。
