# R0 手机验收

由助手先完成构建、安装和日志；用户仅操作手机并反馈体验。以“设置 → 关于”显示的实际版本和构建号为准。

1. **启动**：打开 Tag Music；预期中文曲库空状态，无闪退，尚不提供导入或播放按钮。
2. **导航**：依次点曲库、标签、歌单、设置；预期底部导航可用，标题与页面一致，无内容截断。
3. **主题**：设置中切浅色、深色、跟随系统；预期立即变更，文字可读。
4. **重启保留**：选深色，结束应用后重新打开；预期仍为深色。
5. **版本与诊断**：设置中核对版本/构建号，复制诊断信息并粘贴到本机便笺；预期含版本、R0、应用标识、系统和代码版本，不含密钥。
6. **覆盖安装保留**：保持深色，由助手安装下一构建号后重新启动；预期版本号增加、深色保留，无需卸载。此项需要助手实际完成升级后再反馈。
7. **系统字体与旋转**：放大系统字体并横竖屏切换；预期页面可滚动、导航和主题可操作，无溢出或闪退。验后可恢复原系统字体。

反馈格式：

```text
构建号：0.1.0+…
通过：1、2、…
失败：…，实际表现是……
未测试：…
```

未反馈的项目保持“待手机验收”。不得用自动测试代替用户体验反馈。
