# R8 备份和重新定位

## 已实现

- **设置 → 备份与恢复** 导出版本化的 `.tagmusic` 文件，包含曲库记录、标签、普通与智能歌单及筛选规则。恢复时先核对版本与校验值，展示备份内容数量并等待确认。数据库在一次事务中替换，提交前保存恢复前的数据，可通过同一入口撤回。外部备份中的新目录需重新选择，已有本机位置只有在文件位置和曲库身份对应时才保留可用状态。
- **设置 → 管理目录 → 重新定位** 选择新目录后预览匹配结果。先看原文件身份和相对路径，再用已缓存的 SHA-256 找回改名或换子目录的文件。相同内容有多份且无法唯一匹配时，留在待处理列表。用户确认后保留原歌曲 ID、标签和歌单关联。
- **歌曲 → 查看失联歌曲 → 歌曲操作 → 重新关联文件** 在重新选择的目录中搜索并指定文件。已关联到另一条歌曲记录的文件不可重复关联。
- **管理目录 → 保存搬家指纹** 在原文件仍可访问时手动开始。分批保存已读指纹，支持取消，期间可继续浏览和播放。首次启动及常规扫描无需计算全库指纹。
- 数据库升级到 schema v5，更新了已有的迁移测试预期，增加了 v4 数据样本。Android 使用系统文件选择器读写备份，重新定位只在确认应用时持久化所选目录的只读授权。
- 播放页新增可搜索、勾选多个普通歌单的「添加到歌单」，以及直接切换「我喜欢」成员状态的爱心。两个按钮随原有四个按钮在沉浸模式下隐藏。新库默认创建普通歌单「我喜欢」，恢复同名旧歌单时保留原成员。
