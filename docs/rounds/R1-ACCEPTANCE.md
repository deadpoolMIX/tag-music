# R1 手机体验验收

目标版本：`0.2.0+7`（已原签名覆盖安装；六格式/进度/30次切歌自动回归通过，Android 锁屏卡片针对性自动复验尚未执行）。+6 用户反馈除锁屏卡片外其他正常；锁屏文本跳动、点击偶发无响应及图标反向未通过。
状态：开发中。+7 待补足锁屏自动复验，再进行以下手机验收；未执行不算通过。Windows 不要求锁屏或软件外媒体卡片，只要求后台播放。

助手负责经交互确认后的覆盖安装、原创合成音样本传入 `Music/TagMusic-R1`、日志和故障修复。沿用应用 ID/签名，不卸载、不清数据。系统安装确认与首次目录授权由用户在手机允许。

| 项 | 操作 | 预期 |
|---|---|---|
| 1 | 检查版本和原先主题；重新打开已授权目录 2，选择目录时取消一次 | 版本 +7、主题保留；6 种音频加坏 MP3 共 7 个文件；无需重复授权，取消不清空列表 |
| 2 | 分别点 MP3、FLAC、M4A/AAC、WAV、OGG、Opus 中文样本 | 均能听到低音量测试音，显示“中文测试音 / Tag Music”，文件名中文正常 |
| 3 | 播放时拖动进度，暂停后等待，再恢复；停止后再播放 | 拖动后从新位置继续；暂停进度稳定；恢复/停止后重开正常 |
| 4 | 完全结束应用后重新打开，点“重新打开目录 → 已授权目录” | 不需重新授予目录权限即可列出样本；重启默认不自动播放。本轮不保存曲目列表和播放位置 |
| 5 | Android 播放后回桌面、锁屏，在两首有效曲目间反复切换，并反复点卡片暂停/继续；若有进度条再拖动 | 标题/歌手不先变一行再跳两行；每次点击生效，实际播放显示Ⅱ、暂停显示▶，声音与图标同步；不需要靠切歌恢复。当前系统卡片拖动仍未验证，应用内拖动由第3项验收 |
| 6 | 在六种有效音频间反复切换，或连续点击上下首至少 30 次 | 无崩溃、卡死或误播放旧曲；助手另核对管理描述符与本应用进程日志 |
| 7 | 点“坏文件.mp3”，随后选一个正常文件；再重开目录 | 坏文件显示可理解的错误或元数据降级；正常曲目仍可播放，目录授权及主题保留 |

反馈格式：`构建号：…；通过：…；失败：…（实际表现）；未测：…`。

这份清单验证 R1 技术链路。大量歌曲持久曲库、标签/歌单、复杂音频焦点/蓝牙回归不属于本轮通过结论。

2026-10-30 更正：旧清单将系统卡片拖动视作必然可用，实际 Vivo 卡片当前只展示上下曲和暂停/继续。保留拖动未验证边界，不将 API 声明 seek 等同系统界面已提供进度条；R1 计划要求的进度控制已通过应用内拖动验证。
