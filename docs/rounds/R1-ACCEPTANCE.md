# R1 手机体验验收

当前安装 **0.2.0+9**。R1仍开发中，**锁屏项待手机验收**；设备自动输入已结束，按用户要求不再反复自动测试亮屏时序。手机当前自动播到坏MP3错误页，请先解锁并选正常歌曲。

这次先集中验证下面5项。建议选两首你熟悉、标题不同的正常歌曲；也可先用样本目录的前两首有效音频，在它们之间上下切换，避开末尾坏MP3。

| 项 | 操作 | 通过标准 |
|---|---|---|
| 1 | 正常歌曲开始播放后回桌面并锁屏，等屏幕自然熄灭 | 声音持续，无意外暂停、旧曲回放或卡死 |
| 2 | 锁屏卡片交替暂停/播放10轮；每次点一下，等它生效再点下一次 | 每次及时生效，不需靠切歌恢复；暂停无声并显示▶，播放有声并显示Ⅱ |
| 3 | 锁屏卡片上下曲交替约10次，过程中插入暂停/继续 | 能切到正确曲目；声音、图标和歌曲信息始终对应，无偶发失灵 |
| 4 | 在上述切歌过程中观察标题和歌手 | 内容正确；保持两行显示，不先挤成一行再跳成两行 |
| 5 | 分别在播放和暂停状态，让屏幕自然熄灭再唤醒，总共重复3次 | 播放/暂停状态保持，图标与声音一致，唤醒后卡片按钮仍能使用 |

任一项出现一次异常就可以停止并反馈，不必继续凑次数。请回复：`+9；通过：…；失败：…（操作和实际表现）；未测：…`。异常的大约手机时间有助于助手查日志，不需要你分析原因。
