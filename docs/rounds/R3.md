# R3 标签管理

## R3 当前执行计划

目标：双端扁平多标签管理；标签创建、改名、确认删除，单曲与显式勾选歌曲的批量添加/移除；数据库关系完整、失联保留、旧库升级安全。R4 才实现组合筛选。验收依据为 [PLAN](../PLAN.md#3-开发阶段与交付) 和 [手机清单](R3-ACCEPTANCE.md)。

1. 数据层：schema v2 的 `tags`、`song_tags`、外键和索引；v1→v2 显式迁移、DDL 基线和相关测试。
2. 操作与界面：标签页、关联歌曲数/列表、单曲编辑、跨搜索保留勾选的批量增删；标签不改当前播放快照。
3. 自动验证：R3 样本和 SQLite 审计覆盖、完整检查、万首标签查询；双端构建及包审计。
4. 实际验收：先按 AGENTS 分端说明并取得本批交互选择，再做 Windows 实际运行及手机覆盖升级、操作和性能验证。记录未验证项，用户验收后收口。

当前产品状态：**待手机验收**。+12 候选已构建审计，Windows用户人工全部通过；手机Codex测试和Release性能测量已完成，待用户最终验收结论。Goal active，阶段未complete。
