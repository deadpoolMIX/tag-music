# R2：本地音乐库

## 2026-10-30 开始实施

- 目标：持久化曲库、多目录递归扫描、增量刷新、取消、基础封面、搜索排序及失联保留。入口确认 R1 已双端通过（0.2.0+9，源码51f4af1），本对话仅推进R2。
- 设计：Drift / SQLite schema v1，歌曲使用UUID，位置独立关联到多个根目录；只有某根目录完整扫描成功才提交该根目录的新快照，取消/授权失败/子目录失败均保留此前数据。文件消失保留歌曲及UUID；重现恢复。按位置、大小及修改时间判断增量，未知修改时间重新读取。
- Android继续只读SAF和借用FD，不推导真实路径；目录分页列举支持取消，播放不因扫描或搜索而停止；点击曲目生成独立的可用歌曲播放快照。
- 当前状态：开发中。尚无R2构建、运行或手机验收证据。影响使用的设备操作另按AGENTS交互确认。
- 文档依据：Drift官方setup https://drift.simonbinder.eu/setup/ ，依赖以pub解析后的锁文件为准；不以文档示例版本冒充实际锁定版本。
