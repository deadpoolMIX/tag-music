# R3 手机验收清单

候选构建号和测试方式须在实际开始前填写并按 AGENTS 进行当批交互确认。覆盖安装保留旧库，不卸载、不清数据；每项回报“通过编号 / 失败现象 / 未测试”。

1. 从 R2 版本覆盖升级，进入曲库和标签页：原歌曲、目录与设置保留；无标签时可创建。
2. 创建“收藏”和“Rock”，尝试创建大小写不同或带首尾空白的同名标签：正常创建，重复被拒且已有标签不变。
3. 给单曲添加两个标签，改名其中一个，再回到曲库：同一歌曲保留两个关联，改名同步显示。
4. 在曲库进入多选，搜索并勾选两首不同歌曲，改变搜索词后确认已选总数仍为 2；批量添加再移除标签，只有选中歌曲变化。
5. 打开标签页查看关联歌曲和数量；删除有歌曲关联的标签时先核对影响数，取消不变，确认后仅该标签和关系消失。
6. 使已标记歌曲暂时失联并刷新，再恢复目录：歌曲 UUID 对应的标签保留。此项若操作目录会影响用户数据或授权，须在当批范围单列并取得授权。
7. 播放歌曲时编辑其他歌曲标签：当前播放和既有队列保持；退出重开后标签及关联保留。
