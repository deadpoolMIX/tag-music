# R4 候选验收

候选：0.5.0+13，正式包内revision cb0c072。当前仅准备清单，**未授权、未开始设备测试**；构建和包审计结果以HANDOFF及artifacts/R4为准。

## 当批操作与边界

- Windows：解压正式ZIP到本轮独立运行目录；关闭已运行的Tag Music后启动候选，使用原应用数据库。升级前只读备份原SQLite并比较旧表/标签关系；不清数据、不更改原音乐。根据选择由用户人工操作，或专用GPT 6.1 Terra/high子Agent操作。允许的测试更改只含本批新建标签及其关联、筛选配置、搜索排序与播放状态，结束清理本批标签并停止播放。
- Android：核对已安装包后，以正式APK覆盖升级并启动，保留原数据和签名；不卸载/清数据。按选择由用户人工操作，Codex只读ADB观察；或Codex按此范围输入操作。采集仅本App日志、相关界面XML/截图、包信息及媒体状态，证据写本轮目录。
- 两端均可关闭/重启Tag Music、切换其内页面、输入测试标签、播放/暂停/前后切歌。输入手感、可读性及听感需要用户反馈；日志/截图不冒充这些体验通过。
- Windows实际音频：在播放现有合法440Hz测试音时，采集默认输出回环12秒并分析；会包含该输出设备当时的其他声音，不采麦克风。是否执行须当批明确说明并确认，不能复用R3许可。
- 性能附加技术项：分别启动本轮独立Release性能包，运行临时万首合成数据库六场景。Android需安装独立ID app.tagmusic.player.benchmark，运行后可卸载该独立测试包；正式App不卸载。Windows需解压/启动独立基准程序并关闭；仅写临时数据库及本轮JSON报告。此项同样须明确授权。

## 七项功能清单（两端同语义）

准备：从现有可用曲库中选择四首可区分歌曲P/Q/R/S；新建本批独有标签R4-13-A/B/C/E。只给P加A+B，Q加A，R加C，S加C+E；不改原标签。以下“全部”均指可用歌曲，不含失联记录。

| 编号 | 操作 | 预期 |
|---|---|---|
| 1 | 核对版本；覆盖升级/启动后查看曲库及原标签 | 0.5.0+13、原库及标签关系保留，未自动播放；手机记录安装身份及firstInstallTime，Windows逐列比较旧表 |
| 2 | 全部具备框选A+B，任一具备框选C，排除框选E | 准确得到P、R；数量2，顺序与所选排序一致，无额外歌曲 |
| 3 | 分别清空前两框及排除框，测试仅交集、仅并集、仅排除、全部清空 | 仅交集A+B为P；仅并集C为R/S；仅排除E为全部减S；全空为全部可用歌曲 |
| 4 | 全部具备选A、排除选A、任一具备清空；随后任一具备选C；搜索并切回曲库 | 先0首且无可点击结果，再得R/S；搜索仅缩小筛选结果，曲库搜索/排序保持独立 |
| 5 | 恢复第2项条件；改名A；取消一次删除B，再确认删除B；最后删除E | 改名同步而结果不变；取消无变化；确认框说明规则影响；删B后P/Q/R，删E后P/Q/R/S，引用从对应框移除 |
| 6 | 设置非默认排序和包含条件，完全关闭再打开应用 | 规则和排序保留，歌曲搜索词清空，结果重算，启动保持未播放 |
| 7 | 用两首以上结果点击播放，修改条件/标签使结果改变，再按下一首 | 原快照顺序和当前项不被筛选替换；下一首沿原队列，播放控件可用，最终停止播放 |

最终清理：仅删除本批新建标签，清空三框并恢复默认排序，停止播放；原歌曲及原标签不删除。若用户要求保留测试配置，以其最新指令为准并记录。
