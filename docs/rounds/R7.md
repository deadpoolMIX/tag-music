# R7 系统集成与稳定性

## 本批范围与状态

用户于 2026-11-20 确认按最小范围单批实现及构建，日常使用由用户验收。

| 项目 | 实现状态与体验要点 |
|---|---|
| Windows 便携版后台播放 | **已实现。** 关闭窗口后继续播放，左键点托盘图标打开窗口，右键菜单提供上一首、播放／暂停、下一首和退出。图标可能在任务栏右下角的 `^` 中。 |
| Android 通知和锁屏媒体卡片 | **应用侧已实现。** 通知只传单行歌名与三个播放操作，媒体会话保留歌手和专辑。不同版本的 Android 和 OriginOS 可按媒体会话重新渲染，实际卡片高度由系统决定。[Android 媒体控件文档](https://developer.android.com/media/implement/surfaces/mobile) |
| 共用标签弹窗 | **已实现。** 候选列表从搜索框下方延伸至底部操作区上方，标签较多时可继续滚动。 |
| 手机沉浸式播放页 | **已实现。** 可见播放按钮为上一首、播放／暂停和下一首。标准模式仍可编辑歌曲标签。 |
| OriginOS 原子随身听 | **借包名试用版已构建，待 X100 体验。** 用户反馈 58 号接入未成功，已回滚其服务发现声明。59 号复用现有 Android 媒体会话，验证播放、暂停、上一首和下一首。 |

### 原子随身听试用候选

Android `0.7.0+59` 随身听试用包由提交 `3fb4231` 构建。已核对应用 ID 为 `com.luna.music`、桌面名称为「Tag Music 随身听试用版」，签名证书与 58 号一致。保留 Android 标准媒体服务和现有播控。原子随身听能否识别与控制由用户在 X100 体验。Codex 未安装或操作手机。[飞牛音乐兼容包](https://github.com/kuilei0926/FeiNiuMusic#鸿蒙--iqoo--vivo-音乐兼容包非官方) · [Origin Ghost Player 播控实测记录](https://github.com/fvhde/origin-ghost-player/blob/main/docs/DEV.md#how-it-works)

试用版可与正式 Tag Music 共存，使用独立的曲库、设置与目录授权。已安装汽水音乐或使用同一 ID 的兼容包时会发生包名冲突。正式构建使用 `app.tagmusic.player`，加 `-OriginPlayerTrial` 才会生成随身听试用包。
