# R7 系统集成与稳定性

## 本批范围与状态

用户于 2026-11-20 确认按最小范围单批实现及构建，日常使用由用户验收。

| 项目 | 实现状态与体验要点 |
|---|---|
| Windows 便携版后台播放 | **已实现。** 关闭窗口后继续播放，左键点托盘图标打开窗口，右键菜单提供上一首、播放／暂停、下一首和退出。图标可能在任务栏右下角的 `^` 中。 |
| Android 通知和锁屏媒体卡片 | **应用侧已实现。** 通知只传单行歌名与三个播放操作，媒体会话保留歌手和专辑。不同版本的 Android 和 OriginOS 可按媒体会话重新渲染，实际卡片高度由系统决定。[Android 媒体控件文档](https://developer.android.com/media/implement/surfaces/mobile) |
| 共用标签弹窗 | **已实现。** 候选列表从搜索框下方延伸至底部操作区上方，标签较多时可继续滚动。 |
| 手机沉浸式播放页 | **已实现。** 可见播放按钮为上一首、播放／暂停和下一首。标准模式仍可编辑歌曲标签。 |
| OriginOS 原子随身听 | **59 号基础播控已通过用户 X100 体验。** 60 号已实现封面发布，待用户确认原子随身听能显示封面并随切歌更新。 |

### 原子随身听试用候选

用户在 X100 确认 Android `0.7.0+59`（包内 revision `3fb4231`）的原子随身听基础播控生效，封面未显示。试用包使用应用 ID `com.luna.music` 和桌面名称「Tag Music 随身听试用版」。[飞牛音乐兼容包](https://github.com/kuilei0926/FeiNiuMusic) · [Origin Ghost Player 播控实测记录](https://github.com/fvhde/origin-ghost-player/blob/main/docs/DEV.md#how-it-works)

Android `0.7.0+60`（包内 revision `b62dd64`）沿用试用包身份与播控。媒体会话异步发布当前歌曲的封面缩略图，通过文件提供方对 vivo 原子随身听和 SystemUI 按 URI 授予只读访问。已核对 APK 身份、签名和封面提供方配置。用户可覆盖安装 59 号，在 X100 选择两首封面不同的歌曲，确认原子随身听加载封面并随切歌更新。Codex 未安装或操作手机。[Android FileProvider](https://developer.android.com/reference/androidx/core/content/FileProvider)

试用版可与正式 Tag Music 共存，使用独立的曲库、设置与目录授权。已安装汽水音乐或使用同一 ID 的兼容包时会发生包名冲突。正式构建使用 `app.tagmusic.player`，加 `-OriginPlayerTrial` 才会生成随身听试用包。
