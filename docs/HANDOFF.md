# 日常维护交接

R0～R9 开发计划已收尾。后续按日常使用反馈做定向修补。

- **当前版本** 本地 `main`。个人版 `0.9.0`，包内 revision 为 `7fbb676`。Windows 83、Android 正式 84 和原子随身听 85 已核对并交付至 [output](../output/)。
- **当前状态** 新增侧栏「播放次数」和播放模式「混合随机」。自然播完计一次，恢复旧备份时保留相同歌曲的本机次数。测试 105 通过、1 跳过，22 项失败与 `3c26129` 相同，静态检查无错误或警告。三包版本、哈希、原生文件及 APK 签名已核对。见 [R9 验证归档](../artifacts/R9/)。
- **下一步** 用户自行启动便携版或覆盖安装后，验收结束计数、重新进入页面时的排序和混合随机。既有真机回归及公开发行缺口见 [R9 交付记录](rounds/R9.md#用户验收与保留事项)。
- **维护** 按反馈定位相关代码，集中验证，按规则交付三包。定位代码查[架构](ARCHITECTURE.md)，打包查[构建命令](VERIFICATION.md)，工具链或签名故障查[环境](TOOLCHAIN.md)，许可变更查[第三方许可](THIRD_PARTY.md)。
- **历史** 曲库迁移相关看 [R8 记录](rounds/R8.md)。其余阶段资料仅在追溯具体决策时从[计划的历史入口](PLAN.md#历史查询)查阅。
