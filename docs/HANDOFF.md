# 日常维护交接

R0～R9 开发计划已收尾。后续按日常使用反馈做定向修补。

- **当前版本** 本地 `main`。个人版 `0.9.0`，包内 revision 为 `e7b8807`。Windows 89、Android 正式 90 和原子随身听 91 已核对并交付至 [output](../output/)。
- **当前状态** 歌曲、播放次数、歌单、专辑、歌手和标签可在顶栏搜索。歌曲、筛选、歌单及分组详情支持播放全部。详情页改用侧栏入口，Windows 播放页封面下显示粗体歌名和可点击的歌手。三包版本、哈希、原生文件及 APK 签名已核对。本批仅开发和构建，未安装、启动或运行测试。见 [R9 验证归档](../artifacts/R9/)。
- **下一步** 用户自行试用本批交互。上一批「编辑歌曲」的 Android 真机保存仍待用户验收。既有真机回归及公开发行缺口见 [R9 交付记录](rounds/R9.md#用户验收与保留事项)。
- **维护** 按反馈定位相关代码，集中验证，按规则交付三包。定位代码查[架构](ARCHITECTURE.md)，打包查[构建命令](VERIFICATION.md)，工具链或签名故障查[环境](TOOLCHAIN.md)，许可变更查[第三方许可](THIRD_PARTY.md)。
- **历史** 曲库迁移相关看 [R8 记录](rounds/R8.md)。其余阶段资料仅在追溯具体决策时从[计划的历史入口](PLAN.md#历史查询)查阅。
