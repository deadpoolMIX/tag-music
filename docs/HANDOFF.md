# 日常维护交接

R0～R9 开发计划已收尾。后续按日常使用反馈做定向修补。

- **当前版本** 本地 `main`。个人版 `0.9.0`，包内 revision 为 `489b67c`。Windows 92、Android 正式 93 和原子随身听 94 已核对并交付至 [output](../output/)。
- **当前状态** 返回可退出搜索，切换页面清除搜索和多选。详情页顶栏去掉侧栏按钮，侧栏重新排序。歌曲编辑从曲库全屏单选，支持清除选择并保存回原文件。标签列表保留已选项并固定高度。Android 锁定竖屏，Windows 统一分组行高并可保存界面缩放。已核对三包版本、哈希、原生文件、APK 签名及竖屏配置。见 [R9 验证归档](../artifacts/R9/)。
- **下一步** 用户自行安装并验收，重点检查 Android 返回手势、旋转和原文件写回，以及 Windows 界面缩放。本批未安装、启动或运行测试。既有真机回归及公开发行缺口见 [R9 交付记录](rounds/R9.md#用户验收与保留事项)。
- **维护** 按反馈定位相关代码，集中验证，按规则交付三包。定位代码查[架构](ARCHITECTURE.md)，打包查[构建命令](VERIFICATION.md)，工具链或签名故障查[环境](TOOLCHAIN.md)，许可变更查[第三方许可](THIRD_PARTY.md)。
- **历史** 曲库迁移相关看 [R8 记录](rounds/R8.md)。其余阶段资料仅在追溯具体决策时从[计划的历史入口](PLAN.md#历史查询)查阅。
