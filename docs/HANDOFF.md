# 日常维护交接

R0～R9 开发计划已收尾。后续按日常使用反馈做定向修补。

- **当前版本** 本地 `main`。个人版 `0.9.0`，包内 revision 为 `3175676`。Windows 95、Android 正式 96 和原子随身听 97 已核对并交付至 [output](../output/)。
- **当前状态** 设置支持通过同一 Wi‑Fi 手动连接和双向同步标签、歌单、筛选与主题设置。两端保留各自的文件路径和本机设置。备份恢复会预览自动匹配结果、记住目录对应关系并保留缺失歌曲的关联。数据库升至 v7。静态检查及三包版本、签名、原生文件和哈希核对已完成。见 [R9 验证归档](../artifacts/R9/)。
- **验收** 用户已确认局域网同步功能完成。旧库覆盖升级、同步冲突、缺失歌曲补扫和旧备份自动匹配没有逐项验收记录。局域网同步入口与实现见 [架构](ARCHITECTURE.md#局域网同步与备份匹配)。既有真机回归及公开发行缺口见 [R9 交付记录](rounds/R9.md#用户验收与保留事项)。
- **维护** 按反馈定位相关代码，集中验证，按规则交付三包。定位代码查[架构](ARCHITECTURE.md)，打包查[构建命令](VERIFICATION.md)，工具链或签名故障查[环境](TOOLCHAIN.md)，许可变更查[第三方许可](THIRD_PARTY.md)。
- **历史** 曲库迁移相关看 [R8 记录](rounds/R8.md)。其余阶段资料仅在追溯具体决策时从[计划的历史入口](PLAN.md#历史查询)查阅。
