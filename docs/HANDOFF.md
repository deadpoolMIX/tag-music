# 日常维护交接

R0～R9 开发计划已收尾。后续按日常使用反馈做定向修补。

- **当前版本** 本地 `main`。个人版 `0.8.0`，源码检查点和包内 revision 为 `6469f21`。Windows 74、Android 正式 75 和原子随身听 76 已核对并交付至 [output](../output/)。
- **当前状态** 本批调整 Windows 播放栏布局。定向布局测试和静态检查通过，队列测试文件的七项既有失败在修改前的基线上均可复现。三包已核对版本、哈希和 APK 签名。
- **下一步** 用户自行启动或覆盖安装后验收。既有真机回归及公开发行缺口见 [R9 交付记录](rounds/R9.md#用户验收与保留事项)。
- **维护** 按反馈定位相关代码，集中验证，按规则交付三包。定位代码查[架构](ARCHITECTURE.md)，打包查[构建命令](VERIFICATION.md)，工具链或签名故障查[环境](TOOLCHAIN.md)，许可变更查[第三方许可](THIRD_PARTY.md)。
- **历史** 曲库迁移相关看 [R8 记录](rounds/R8.md)。其余阶段资料仅在追溯具体决策时从[计划的历史入口](PLAN.md#历史查询)查阅。
