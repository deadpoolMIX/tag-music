# 子 Agent 短交接协议

## 主 Agent 固定路由

正常只读五字段一行；实际来源核 Agent 句柄，不猜标题用途：

`交给=developer；状态=就绪；配置=normal；输入=已有正文位置@版本；注意=无`

| 交接情况 | 处理 |
|---|---|
| 缺字段、未知接收者、角色/配置不匹配、缺必要输入或版本不符 | 退来源补齐，不猜、不派 |
| 就绪、注意=无 | 按指定角色及 defaults 配置转交，输入引用原样传递；就绪不等于授权 |
| 注意=风险未知 | 交 planner |
| 注意=证据冲突 | 交 reviewer / high_risk，主不读代码/原图裁决 |
| 注意=定位失败2次_已释放 | 仅 phone_tester/phone_visual、旧控制者已停且原批授权有效时转 Terra/high，按[手机执行](roles.md#手机执行)；否则保持停止 |
| 注意=需授权/需解锁/需用户决策 | 停相关操作，主读短授权/决策摘要交用户 |
| 状态=失败/阻塞或其他异常 | 停正常推进，交明确指定角色；去向不明退回 |
| 交给=main；状态=审查通过；配置=无；注意=无 | 仅实际来源为独立 reviewer、输入版本匹配且写入/设备已释放时收口；其他角色完成只代表可交下一角色 |

角色→配置白名单：planner→planner；developer→simple/normal/high_risk；reviewer→acceptance/high_risk；command_runner→command_runner；phone_tester→phone_script/phone_visual；windows_tester→windows_gui；main→无。

main 仅为协调/授权/阻塞或审查收口目的地，不 spawn main；回 main 状态仅阻塞、失败、审查通过。缺输入/授权可用“交给=main；状态=阻塞；配置=无；输入=缺项或授权摘要位置@版本；注意=需授权/缺输入等具体标志”。短说明无现成位置时直接附，不为此建文件。

## 标题、摘要、内容

- 标题层即五字段。“输入”须可定位必要正文/精确差异并标候选、提交或工作项版本；“配置”编码已判执行档位，理由留正文供接收者/reviewer 核验，不加第六字段。“注意”必须显露失败、未测、风险、授权和清理限制，不能藏正文。
- 摘要层可省，仅沟通、授权、异常/决策时给必要几句话。
- 内容层由对应角色直接读必要部分，优先已有计划、验收记录、差异与证据，不默认读全目录。执行结果和审查正文要求见 [roles.md](roles.md)。主仍须掌握用户目标、阶段、配置、资源、阻塞和既有授权，不能仅凭“完成”验收。

交接条默认是消息，不落盘、不建卡片/文件夹。短任务可直接附必要原文；长内容无持久入口且确需保存时，由来源角色仅保存一次，后续传引用，不全文回灌主聊天。常规步骤不逐条消息；在批次完成、需决策、授权变化、阻塞或失败门槛时回传。分层不是文件访问隔离，不能消除已进入主聊天的内容，也不保证固定额度节省。

## 交接去向

| 来源 | 下一角色 | 必要输入 |
|---|---|---|
| planner：实施计划 | developer | 原始需求、计划、必要实现入口 |
| developer：实现交付 | 原 planner | 原始需求、实际差异、完成/未完成项，不能缩成仅验开发声明 |
| planner：测试计划 | command_runner/对应端 tester | 步骤、定位、断言、证据与授权；多项独立任务给多条卡，不让主拆正文 |
| command_runner/tester | reviewer | 需求、差异、结果及原始证据 |
| reviewer：修复/补查 | developer/planner/原 tester | 定向问题和必要上下文 |
| reviewer：完整通过 | main | 仅短卡，正文留原处 |

有效计划/测试/审查按缺口更新；简单文档跳过设备/构建等无关角色，不新增“传文件”“写摘要”“测试计划”角色。角色扩展须经 [SKILL 审批规则](../SKILL.md#角色配置与路由)。单元内复用、单元后禁复用与独立审查、Flutter/设备/写入排程见 [资源约束](../SKILL.md#派发与资源约束)。

## 派发提示词

> 你是 `<角色>`，项目 `D:\.projects\Tag Musicplayer`，配置 `<defaults模型/强度>`，输入 `<引用@版本>`。遵守 AGENTS、SKILL 公共边界及 roles.md 自身小节（设备任务另读共同要求）。只写 `<允许路径>`；设备授权 `<本批授权或无操作>`，资源 `<占用/释放约束>`。直接读必要正文，完成仅回五字段；缺输入或越权停相关工作并交回。

显式 `fork_turns: none`、model、reasoning_effort，不附主聊天全文；首次输入若为未落盘用户要求，附必要原文，不能只给不可读消息编号。请求配置以 defaults 为准，实际配置无可信元数据记未验证。

派发前确认旧 Agent 已停写/控制，失联不能推定释放；失败计数保留。手机先由主读取 planner 的短授权摘要，含 5–8 项操作/预期、候选、执行者、工具限制、清理及定位升级安排，向用户呈现并等明确回复；密码用户处理。授权、暂停、解锁和压缩依 [AGENTS.md](../../../../AGENTS.md)，交接卡不创造授权。仅用户决策确需时主读必要摘要，不重复专业角色的内容核验。
