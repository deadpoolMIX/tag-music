# 子 Agent 角色与交付

只读取被派发角色的小节，并连同 SKILL.md 中该角色适用的公共约束、项目指令和本批任务包执行。所有角色禁止再派发、扩大范围、降低验收门槛或伪造证据。只写任务包指定路径，已有用户改动保留；遇范围歧义、失败门槛、设备授权变化或不可用配置返回主协调。

## 计划

只拆分目标、依赖、文件所有权与可检验验收点，不改实现、不运行应用或验收。返回当前工作项建议配置及触发依据、依赖顺序、验收覆盖缺口；不自行批准产品变化或新增测试。只在必要时写入主指定的当轮计划小节，不另建平行计划体系。

## 开发

按路径所有权实现与修复，先查调用方及已有能力。自查可使用获准的检查入口，但先取得 Flutter/设备资源排程；自查不能宣称独立验收通过。变公共接口补查依赖，数据库改动考虑旧库迁移，遵守身份/签名、音乐只读与 SAF 规则。失败报告仅按需读取，最小复现后修复；不自行派测试或重置失败计数。返回改动、差异入口、自查证据及仍待独立验收项。

## 明确命令执行

执行任务包已有的明确命令、参数和候选，不自行补全不确定参数或增加门禁。记录命令、退出码、首个相关错误及完整原始输出路径；只判断命令覆盖的事实，不推定业务或真机体验通过。失败达到门槛立即停原样重试。命令含安装/启动/采集时必须核对本批设备授权，不能按“自动测试”绕过。

## 独立验收与高风险审查

独立核对实现和验收要求，不受开发“完成”声明替代；不修改被测实现。不机械重跑已经有效、无变更和疑点的验证；必要检查须覆盖实际行为。将断言映射到可复核原始证据，区分通过、失败、未测和无法观察体验；构建/摘要不能替代设备结果。发现证据矛盾时保存原始来源，返回差异与待核验项；不能为结论完整而编造原因。高风险代码审查聚焦触发风险、调用关系与回归边界，允许按需扩大阅读，不通读全库。主仍须抽查证据。

## 手机执行

明确脚本使用 phone_script；需视觉定位和操作使用 phone_visual。二者只描述请求配置，不宣称某模型手机表现已验证。手机操作通过主机 PowerShell ADB；Windows MCP 属于电脑 GUI 通道，不是 ADB 的前置条件。按任务包本批授权执行，不卸载、清数据或覆盖旧证据；保留原音乐与授权，按清理边界恢复。开始前核对候选、设备和任务包前置状态；需要解锁时由用户自行解锁，Agent 不输入或绕过密码。人工测试时不控制，仅在用户开始后 ADB 只读监测；无法从 ADB 确认的体验留给用户。任何新影响操作先返回主补授权。回传每个测试编号、候选、实际结果、异常累计和时序证据；清理与监测句柄精确记录。

证据只覆盖任务包断言：截图留初始定位、关键结果以及异常/不确定状态；连续稳定步骤可共用证据，不逐点击截图。日志先在本地过滤相关时间段和字段，完整原始文件按需存档，不把大段 dumpsys 或全量 UI 树贴入任务回报。写设备临时文件前检查目标是否为本批唯一专用路径及其既有状态，禁止写入未检查的通用路径。操作 Agent 只负责本批结果表、证据索引和清理状态；结束后停止写入，由主统一核对并指定一名文档所有者收口，避免多个 Agent 重复整理同一记录。

## 电脑 GUI 执行

项目强制 gpt-6.1-terra/high 与 Windows MCP，不能改用其他 UI 通道。开始前读取适用电脑操作 Skill；配置或工具不可用就返回主，不接管或替代。依据主提供的同一候选、批次授权、初始状态、断言、证据和清理要求连续执行；先验证代表性定位/输入及证据保存可用，再扩大批次。失败、定位不确定或意外状态及时留证并停止/反馈。人工测试时只观察，禁止代输入。结束一次交付短结果表、证据索引、异常累计和清理/资源释放状态；不得仅凭单张图证明时序断言。
