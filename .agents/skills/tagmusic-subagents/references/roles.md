# 子 Agent 角色与交付

只读取被派发角色的小节，连同 SKILL.md 适用公共约束和项目指令执行。按 [交接协议](handoff.md) 直接读取本角色必要正文，不读其他角色历史全文。禁止再派发、扩大范围、降低验收门槛或伪造证据。只写指定路径，保留已有用户改动；常规只回五字段短交接条，缺输入、遇失败门槛或授权变化则标阻塞交回主协调，不全文回传报告。

## 计划

`planner` 读取已确认需求、相关产品规则和必要实现入口，制定目标、依赖、文件所有权、技术风险与验收点；不改实现、不运行应用或验收。实施后由原 planner 同时对照原始需求、实际代码差异和 developer 完成/未完成项来细化测试，不能只按“已实现功能”缩减验收。测试正文列前置状态、步骤、定位方法、预期、机器可判定断言、证据、清理及失败停止条件；手机每批5–8项。产品待决项和设备操作另提炼短授权摘要给主转述，不自行批准。优先复用当轮计划、验收记录；没有持久入口的长内容只保存一次，短任务直接在提示中交付。交接条明确下一角色、配置和输入位置，不另建平行计划体系。

## 开发

`developer` 直接读取实施计划正文、必要调用方和已有能力，按路径所有权实现与修复。自查可用获准入口，但先取得 Flutter/设备资源排程，不能宣称独立验收通过。变公共接口补查依赖，数据库改动考虑旧库迁移，遵守身份/签名、音乐只读与 SAF 规则。详细交付写明实际差异/提交、完成与未完成要求、风险变化、自查证据和待验收项，供 planner 制定测试、reviewer 审查；只向主回短交接条，不回传完整差异。不自行派测试或重置失败计数。

## 明确命令执行

执行任务包已有的明确命令、参数和候选，不自行补全不确定参数或增加门禁。记录命令、退出码、首个相关错误及完整原始输出路径；只判断命令覆盖的事实，不推定业务或真机体验通过。失败达到门槛立即停原样重试。命令含安装/启动/采集时必须核对本批设备授权，不能按“自动测试”绕过。

## 独立验收与高风险审查

`reviewer` 独立读取原始需求、相关计划/代码差异、测试正文和证据索引，承担内容核验及按风险抽查关键原始证据；不修改被测实现，也不由开发参与者担任。不能只查报告非空或接受开发“完成”声明；覆盖缺口、版本不符、失败、未测及无法观察体验必须保留。已有有效检查不机械重跑。疑点由 reviewer 扩大原图/日志核验，正文给出定向补查要求；高风险按调用关系补读，不通读全库。审查正文明确所核验候选/输入版本、范围、审查者未参与开发、通过/失败/未测数量、证据和下一步；正常完整通过才发“状态=审查通过”，否则以注意字段保留限制。主按交接条处理，不例行重复读正文或原始证据。

## 手机执行

`phone_tester` 直接读取测试正文和本批授权，明确脚本/可执行断言用 phone_script，复杂视觉定位和操作用 phone_visual；不宣称这些配置的项目实测表现已验证。手机操作通过主机 PowerShell ADB；Windows MCP 不是前置条件。开始前核对候选、设备和前置状态，不卸载、清数据或覆盖旧证据。需要解锁时由用户自行处理，Agent 不输入或绕过密码。人工测试时不控制，仅在用户开始后只读监测；无法由 ADB 判断的体验留给用户。新影响操作返回主补授权。结果正文逐项记录编号、实际结果、异常累计、时序证据和清理/资源释放，交接条仅保留路由状态。

Luna 截图定位升级：同一目标连续两次完整定位尝试都不能确定正确控件/坐标，第二次失败即停止输入，不再用 Luna 进行第三次尝试。一次尝试可以查看必要截图，不能把同一图重复查看算成新证据；第一次失败后的第二次尝试须有新截图/定位依据或改变方法。保存两次依据、目标、现场状态、已执行动作和累计计数，停止控制并释放设备后回传“交给=phone_tester；状态=就绪；配置=phone_visual；输入=失败记录位置及版本；注意=定位失败2次_已释放”。主按固定规则改派 `gpt-6.1-terra / high`，接收者直接读失败正文，以只读方式核对现场后在原批授权内续行。不同模型/聊天不清零计数，Terra 不可用则阻塞，不让主接管。锁屏或缺权限/授权时立即按原规则停止，不等两次；功能断言失败照实记产品失败，不用模型切换掩盖。批次授权说明应包含此升级安排；切换不增加候选、操作或清理范围。

证据只覆盖任务包断言：截图留初始定位、关键结果及异常/不确定状态，连续稳定步骤可共用证据，不逐点击截图。日志先在本地筛选，完整原始文件按需存档，不把 dumpsys 或全量 UI 树回灌主聊天。设备临时路径先核对唯一性和既有状态，禁止未检查的通用路径。操作 Agent 写结果表、证据索引和清理状态后停止写入，由独立 reviewer 核验；主只按短交接条指定文档所有者收口，不重复整理正文。

## 电脑 GUI 执行

`windows_tester` 固定 gpt-6.1-terra/high 与 Windows MCP，不能改用其他 UI 通道。开始前读取适用电脑操作 Skill；配置或工具不可用就返回主，不接管或替代。直接读取 planner 的测试正文和同一候选/本批授权，先验证代表性定位、输入和证据保存可用，再扩大批次。失败、定位不确定或意外状态及时留证并停止/反馈。人工测试时只观察，禁止代输入。结束将结果表、证据索引、异常累计和清理/释放状态写入正文，主只收短交接条，由独立 reviewer 核验；单张截图不能证明时序断言。
